# 09 · Lucide icons

Status: done

## Goal

Every icon in the app, including the native iOS/Android tab bar, is a Lucide icon, so the app has one consistent outline icon style on all platforms.

## Decisions

- In-app icons use `lucide-react-native` (renders through `react-native-svg`, already installed at 15.16.0; peer range `^12–^15`). Install with `npx expo install lucide-react-native`. It's pure JS, so Expo Go still works and no development build is needed.
- `Icon` keeps its public API (`name`, `size`, `color: ColorToken`, `style`), so call sites only change if they pass a raw name. `IconName` becomes a Lucide component type (`LucideIcon`) instead of `{ ios, android, web }`.
- Lucide stroke width: one value, `iconStroke = 2` (Lucide default), added to `src/theme/values.js` and re-exported from `@/theme`. Small icons (≤16) keep the same stroke; no per-size tuning.
- Mapping (key in `icons` → Lucide): plus → `Plus`, minus → `Minus`, close → `X`, check → `Check`, chevronDown → `ChevronDown`, chevronLeft → `ChevronLeft`, calendar → `Calendar`, home → `House`, entries → `List`, categories → `LayoutGrid`, forecast → `ChartLine`.
- **Native tab bar** (user's choice): `NativeTabs` only takes SF/Material names or image sources, so the four tab icons are pre-rendered Lucide PNGs passed via `NativeTabs.Trigger.Icon src={…}` with `renderingMode="template"` so the system tints them with `iconColor` (`textBlackSoft` / `greenAccent`).
- Tab PNGs: black glyph on transparent, 25pt canvas (iOS tab bar size; Android uses the same files) at @1x/@2x/@3x = 25/50/75 px, stroke 2 at 24-unit Lucide scale, centered. Files: `assets/images/tabs/<tab>.png`, `<tab>@2x.png`, `<tab>@3x.png`.
- Selected state: Lucide has no filled variants, so selected uses a heavier stroke (2.5) as a `-selected` PNG set (`src={{ default, selected }}`) plus the tint change. Web tab bar does the same with `strokeWidth`.
- PNGs are generated by a committed script, `scripts/build-tab-icons.mjs`, which reads SVGs from the `lucide-static` dev dependency (same version as `lucide-react-native`) and rasterizes them with Playwright (already a dev dependency). Re-run it when a tab icon changes; PNGs are committed.
- `expo-symbols` is removed from `package.json` once nothing imports it.
- `TABS` entries drop `sfSelected`; each tab gets `icon` (Lucide component, for web) and `image: { default, selected }` (required PNGs, for native).

## Out of scope

- New icons or new places that show icons.
- App icon, splash screen and favicon (not Lucide).
- Per-size stroke tuning or animated icons.

## Steps

### 1. Install Lucide and switch `Icon`

- `npx expo install lucide-react-native`, then `npm i -D lucide-static@<same version>`.
- Add `iconStroke: { regular: 2, selected: 2.5 }` to `src/theme/values.js` and export it typed from `@/theme`.
- Rewrite `src/components/ui/icon.tsx`: `export type IconName = LucideIcon`; `Icon` renders `<Glyph size={size} color={colors[color]} strokeWidth={strokeWidth ?? iconStroke.regular} style={style} />` with an optional `strokeWidth` prop; `icons` maps to the Lucide components listed in Decisions. If NativeWind needs it for `className` on Lucide (we don't pass one), skip `cssInterop`.
- Every caller (`button`, `float-button`, `stepper`, `modal`, `checkbox`, `accordion`, `select-field`, `date-field(.web)`, `back-link`, `scroll-hint`, `item-row`, `sheet-header`, `hero`, `entries`) already uses `icons.*`, so it should compile unchanged. Typecheck confirms.
- Done when: `npx tsc --noEmit` passes and web screens show Lucide icons.

### 2. Generate tab PNGs

- Write `scripts/build-tab-icons.mjs`: for each tab `{ file, lucide }` (`home: house`, `entries: list`, `categories: layout-grid`, `forecast: chart-line`) and each variant (`regular` stroke 2, `selected` stroke 2.5), load `node_modules/lucide-static/icons/<lucide>.svg`, set `stroke="#000"` and `stroke-width`, render in a Playwright Chromium page with transparent background at viewport 25×25 and deviceScaleFactor 1/2/3, and screenshot with `omitBackground: true` to `assets/images/tabs/<file>[-selected][@2x|@3x].png`.
- Add `"icons:tabs": "node scripts/build-tab-icons.mjs"` to `package.json` scripts, run it, and add `assets/images/tabs/CREDITS.md` (Lucide, ISC license, lucide.dev).
- Done when 24 PNGs exist (4 tabs × 2 variants × 3 scales) and look right when opened.

### 3. Wire the tab bars

- `src/features/tabs/tabs.ts`: replace `sfSelected` with `image: { default: require(...home.png), selected: require(...home-selected.png) }` per tab; type `image` as `{ default: ImageSourcePropType; selected: ImageSourcePropType }`.
- `app-tabs.tsx`: `<NativeTabs.Trigger.Icon src={tab.image} renderingMode="template" />` (drop `sf` and `md`).
- `app-tabs.web.tsx`: pass `strokeWidth={focused ? iconStroke.selected : iconStroke.regular}` to `Icon`.
- Remove `expo-symbols` (`npm uninstall expo-symbols`) after `grep -r expo-symbols src` is empty; run `npx expo-doctor`.
- Done when native and web tab bars show Lucide icons that tint on selection.

## Verification

- `npx expo lint`, `npx tsc --noEmit`, `npx expo-doctor` pass.
- Web (Playwright screenshots): Home (hero `+` button, tab bar with Home selected), Entries, Add entry sheet (close X, date calendar, select chevrons), onboarding fields (back chevron, stepper ±, item-row X). No missing or blank icons; colors match before.
- iOS simulator in Expo Go: tab bar icons are Lucide, tinted `textBlackSoft` and `greenAccent` when selected, sharp (not blurry), sized like the old SF Symbols; in-app icons render.
- Android (if an emulator is available): same tab bar check.
- End to end: fresh launch → onboarding → Home → open Add entry → save → Entries tab; every icon on that path is Lucide.
